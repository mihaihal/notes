# Notes vault

A personal, local notes vault. Notes are written from podcast transcripts,
YouTube transcripts, and conversations with Claude, then read in the browser.
No server, no database, no framework. Double-click `index.html` and it works.

## How it works

1. Each note is a Markdown file in `vault/`, with a small front matter block
   (title, source, link, date, tags).
2. `python3 build.py` bundles every note into `notes.js`.
3. `index.html` loads `notes.js` and renders the notes with search, source
   and tag filters, and a collapsible full writeup.

The Markdown files are the source of truth. `notes.js` is generated output
and is never edited by hand.

## Reading notes

Open `index.html` in a browser (Chrome or Firefox, straight from disk).

- The sidebar lists notes newest first. Click one to read it.
- Each note opens on its **glance**: a short intro and 5-10 takeaways you
  can skim in a minute. Click **Show full writeup** for the long version.
- Type in the search box to filter. Every word you type must appear somewhere
  in a note for it to stay listed. If a match lives only in the full writeup,
  that section opens automatically.
- Filter by source with the chips (All, Podcast, YouTube, Conversation) and by
  tag with the tag list. Click a selected tag again to clear it.
- Keyboard: `/` focuses search, `Escape` clears it.
- The URL hash remembers the open note, so reload and bookmarks return to it.

## Adding a note

1. Copy `templates/note.md` to `vault/YYYY-MM-DD-slug.md`, dated the day the
   note is written.
2. Fill in the front matter. `title`, `source`, and `date` are required.
   `source` must be `podcast`, `youtube`, or `conversation`. `url`,
   `published`, `author`, and `tags` are optional.
3. Write the glance above `## Full writeup` and the long version below it.
4. Run `python3 build.py` and reload the page.

The build fails loudly, naming the file, if a note is missing a required
field or has an unknown source. Raw transcripts can be kept in `sources/`;
they are not bundled.

In practice Claude writes the notes: hand it a link or a transcript and it
produces the file, runs the build, and reports the top takeaways.
`CLAUDE.md` holds the rules it follows.

## Layout

```
index.html            viewer
viewer.js             viewer logic (search, filters, rendering)
style.css             viewer styles, light and dark
vendor/marked.min.js  Markdown renderer (marked 15.0.7, vendored)
notes.js              GENERATED by build.py
build.py              bundles vault/*.md into notes.js
vault/                the notes, one Markdown file each
sources/              raw transcripts, not bundled
templates/note.md     blank note
tests/                Python tests for build.py, Node tests for viewer.js
docs/superpowers/     design spec and implementation plan
claude-config/        lessons and task log for Claude sessions
CLAUDE.md             instructions for Claude
```

## Requirements

Python 3 and Node (for tests only). No packages to install.
