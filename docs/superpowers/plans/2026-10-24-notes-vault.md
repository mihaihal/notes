# Notes Vault Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local, no-server notes vault: Markdown notes in `vault/`, a `build.py` that bundles them into `notes.js`, and a static `index.html` viewer with search, filters, and a collapsible full writeup.

**Architecture:** Markdown files with a hand-parsed `key: value` front matter are the source of truth. `build.py` (stdlib only) emits `window.NOTES = [...]` into `notes.js`. `index.html` loads `vendor/marked.min.js`, `notes.js`, and `viewer.js` as classic scripts and does all filtering and rendering client-side from `file://`.

**Tech Stack:** Python 3.14 (stdlib, `unittest`), vanilla HTML/CSS/JS, `marked` 15.0.7 vendored, Node 26 built-in test runner for viewer logic tests.

**Spec:** `docs/superpowers/specs/2026-10-23-notes-vault-design.md`

## Global Constraints

- No tool installs. Python stdlib only in `build.py`; no npm packages. The single allowed download is `vendor/marked.min.js`.
- Git is the owner's. No task runs any state-changing git command. There are no commit steps; the owner commits.
- Viewer must work from `file://`: classic `<script>` tags only, no ES modules, no `fetch()`.
- `notes.js` is generated by `build.py` and kept in the tree; never hand-edited.
- Required front matter: `title`, `source`, `date`. `source` ∈ {`podcast`, `youtube`, `conversation`}. Build fails loudly (non-zero exit, file named) on violation and leaves `notes.js` untouched.
- Glance = body before `## Full writeup` (case-insensitive, trimmed); full = from that heading on; missing heading ⇒ whole body is glance.
- Notes sorted by `date` desc, then `title` asc.
- Search: whitespace-split terms, every term a case-insensitive substring of `text`; `text` = title + author + tags + glance + full, lowercased.
- Auto-expand full writeup when all terms match the note but at least one term is absent from title + tags + glance.
- `/` focuses search, `Escape` clears and blurs. Hash `#<id>` selects a note; missing or filtered-out id falls back to newest visible note.

## Review Focus

1. A note body containing `</script>` must not break `notes.js` as a script (JSON escaping does not cover it). Test in Task 3.
2. A front matter value containing `:` (every URL) must survive intact. Test in Task 2.
3. A file with no front matter, or front matter never closed, must fail with the file name in the message, not a stack trace. Test in Task 2 and Task 3.
4. Empty `vault/` must produce `window.NOTES = [];` and the viewer must show the empty state rather than throw. Test in Task 3 and Task 4.
5. A query of only whitespace must behave like an empty query (all notes shown). Test in Task 4.

### Task 2: Front matter and body parsing

**Files:**
- Create: `build.py`
- Test: `tests/test_build.py`

**Interfaces:**
- Produces:
  - `class NoteError(Exception)` — message always starts with the note's path.
  - `parse_front_matter(text: str, path: str) -> tuple[dict[str, str], str]` — returns `(meta, body)`. Raises `NoteError` if text does not start with `---` line or the closing `---` is missing. Splits each line on the first `:`; keys stripped, values stripped; blank lines inside ignored.
  - `split_body(body: str) -> tuple[str, str]` — returns `(glance, full)`. `full` starts at the `## Full writeup` heading line (matched case-insensitively after strip) and includes it; `""` when absent. Both stripped.
  - `parse_tags(value: str) -> list[str]` — comma-split, stripped, lowercased, empties dropped; `""` ⇒ `[]`.

```python
# tests/test_build.py
import unittest
from build import NoteError, parse_front_matter, split_body, parse_tags

FM = "---\ntitle: Pricing\nsource: podcast\nurl: https://x.io/e/1\ndate: 2026-10-23\ntags: a, B ,,c\n---\nIntro.\n\n## Takeaways\n- one\n\n## full writeup\n\n### Part\ntext\n"

class ParseFrontMatter(unittest.TestCase):
    def test_splits_on_first_colon_only(self):
        meta, _ = parse_front_matter(FM, "n.md")
        self.assertEqual(meta["url"], "https://x.io/e/1")
    def test_returns_body_after_closing_fence(self):
        _, body = parse_front_matter(FM, "n.md")
        self.assertTrue(body.startswith("Intro."))
    def test_missing_opening_fence_names_file(self):
        with self.assertRaisesRegex(NoteError, r"^vault/bad\.md"):
            parse_front_matter("title: x\n", "vault/bad.md")
    def test_unclosed_fence_names_file(self):
        with self.assertRaisesRegex(NoteError, r"^vault/bad\.md"):
            parse_front_matter("---\ntitle: x\n", "vault/bad.md")

class SplitBody(unittest.TestCase):
    def test_splits_at_full_writeup_case_insensitive(self):

        glance, full = split_body(body)
        self.assertTrue(glance.endswith("- one"))
        self.assertTrue(full.startswith("## full writeup"))
    def test_no_heading_means_all_glance(self):
        glance, full = split_body("just text\n")
        self.assertEqual((glance, full), ("just text", ""))

class ParseTags(unittest.TestCase):
    def test_normalises(self):
        self.assertEqual(parse_tags("a, B ,,c"), ["a", "b", "c"])
    def test_empty(self):
        self.assertEqual(parse_tags(""), [])
```

### Task 3: Build notes.js

**Files:**

- Test: `tests/test_build.py`

**Interfaces:**
- Consumes: Task 2 functions.
- Produces:
  - `SOURCES = ("podcast", "youtube", "conversation")`

Raises `NoteError` for missing `title`/`source`/`date` or unknown `source`.   - `main(argv: list[str]) -> int` — vault `vault/`, output `notes.js` relative to `build.py`'s directory; prints one line per note (`<date>  <source>  <title>`) and `built N notes -> notes.js`; on `NoteError` prints `error: <message>` to stderr, returns 1, does not write.

```python
import json, tempfile, pathlib, io, contextlib
from build import build_note, build_all, render_js, main

def write(d, name, text):
    p = pathlib.Path(d) / name; p.write_text(text); return p

GOOD = "---\ntitle: {t}\nsource: {s}\ndate: {d}\n---\nglance {t}\n\n## Full writeup\nfull {t}\n"

class BuildNote(unittest.TestCase):
    def test_fields_and_text(self):
        with tempfile.TemporaryDirectory() as d:
            p = write(d, "2026-10-23-a.md", "---\ntitle: A\nsource: youtube\ndate: 2026-10-23\nauthor: Guest\ntags: x\n---\nG\n\n## Full writeup\nF\n")
            n = build_note(p)
        self.assertEqual(n["id"], "2026-10-23-a")
        self.assertEqual(n["tags"], ["x"])
        self.assertEqual(n["url"], "")
        self.assertEqual(n["glance"], "G")
        self.assertTrue(n["full"].startswith("## Full writeup"))
        for word in ("a", "guest", "x", "g", "f"):
            self.assertIn(word, n["text"].split())
    def test_missing_required_field_fails(self):
        with tempfile.TemporaryDirectory() as d:
            p = write(d, "2026-10-23-a.md", "---\ntitle: A\nsource: podcast\n---\nbody\n")
            with self.assertRaisesRegex(NoteError, r"date"):
                build_note(p)
    def test_unknown_source_fails(self):
        with tempfile.TemporaryDirectory() as d:
            p = write(d, "2026-10-23-a.md", GOOD.format(t="A", s="blog", d="2026-10-23"))
            with self.assertRaisesRegex(NoteError, r"source"):
                build_note(p)
    def test_date_mismatch_warns_only(self):
        with tempfile.TemporaryDirectory() as d:
            p = write(d, "2026-01-01-a.md", GOOD.format(t="A", s="podcast", d="2026-10-23"))
            err = io.StringIO()
            with contextlib.redirect_stderr(err):
                build_note(p)
        self.assertIn("warning", err.getvalue())

class BuildAll(unittest.TestCase):
    def test_sorted_date_desc_then_title(self):
        with tempfile.TemporaryDirectory() as d:
            write(d, "2026-10-01-b.md", GOOD.format(t="B", s="podcast", d="2026-10-01"))
            write(d, "2026-10-02-z.md", GOOD.format(t="Z", s="podcast", d="2026-10-02"))
            write(d, "2026-10-02-a.md", GOOD.format(t="A", s="podcast", d="2026-10-02"))
            ids = [n["id"] for n in build_all(pathlib.Path(d))]
        self.assertEqual(ids, ["2026-10-02-a", "2026-10-02-z", "2026-10-01-b"])
    def test_empty_vault(self):
        with tempfile.TemporaryDirectory() as d:
            self.assertEqual(build_all(pathlib.Path(d)), [])

class RenderJs(unittest.TestCase):
    def test_escapes_script_close(self):
        js = render_js([{"full": "a </script> b"}])
        self.assertNotIn("</script>", js)
        self.assertIn("<\\/script>", js)
        self.assertTrue(js.startswith("window.NOTES = "))
    def test_empty(self):
        self.assertEqual(render_js([]), "window.NOTES = [];\n")

class Main(unittest.TestCase):
    def test_bad_note_leaves_output_untouched(self):
        with tempfile.TemporaryDirectory() as d:
            root = pathlib.Path(d); (root / "vault").mkdir()
            write(root / "vault", "2026-10-23-a.md", "no front matter\n")
            out = root / "notes.js"; out.write_text("OLD")
            err = io.StringIO()
            with contextlib.redirect_stderr(err):
                code = main(["--root", str(root)])
        self.assertEqual(code, 1)
        self.assertEqual(out.read_text(), "OLD")
        self.assertIn("error:", err.getvalue())
    def test_writes_output(self):
        with tempfile.TemporaryDirectory() as d:
            root = pathlib.Path(d); (root / "vault").mkdir()
            write(root / "vault", "2026-10-23-a.md", GOOD.format(t="A", s="podcast", d="2026-10-23"))
            with contextlib.redirect_stdout(io.StringIO()):
                code = main(["--root", str(root)])
            self.assertEqual(code, 0)
            self.assertTrue((root / "notes.js").read_text().startswith("window.NOTES = ["))
```

### Task 4: Viewer logic (pure functions)

**Files:**
- Create: `viewer.js`
- Test: `tests/viewer.test.js`

**Interfaces:**
- Consumes: note objects shaped as `build_note` produces.
- Produces (globals on `window`, also exported via `module.exports` when `module` is defined):
  - `parseQuery(q: string) -> string[]` — lowercase whitespace-split, empties dropped.
  - `filterNotes(notes, {terms: string[], source: string|null, tag: string|null}) -> notes[]` — order preserved; `source`/`tag` `null` means no filter.
  - `shouldAutoExpand(note, terms: string[]) -> boolean` — true when `terms.length > 0`, every term is in `note.text`, and at least one term is absent from `(title + " " + tags.join(" ") + " " + glance).toLowerCase()`.
  - `pickSelected(visible: notes[], hashId: string) -> note|null` — note with `id === hashId` if in `visible`, else `visible[0]`, else `null`.
  - `allTags(notes) -> string[]` — unique, sorted.
